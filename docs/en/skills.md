# Skills and agents

| Name | Phase | Purpose |
|---|---|---|
| `bewerbung-solution` | plan | Front door: profile, analysis, plan approval, documents, quality gate |
| `bewerbung-profil-erfassen` | intake | Builds `bewerbung/profil.md`, the single source of truth |
| `bewerbung-stellenanzeige-analysieren` | analyse | Extracts requirements and matches them to the profile with evidence |
| `bewerbung-lebenslauf-erstellen` | create | Tabular, reverse-chronological German CV |
| `bewerbung-anschreiben-erstellen` | create | One-page DIN-style cover letter, four variants |
| `bewerbung-email-erstellen` | deliver | Cover e-mail, subject, attachment list and file names |
| `bewerbung-pruefen` | review | Quality gate: blockers, warnings, notes |
| `bewerbungs-reviewer` (agent) | review | Read-only whole-set review from a recruiter's perspective |
